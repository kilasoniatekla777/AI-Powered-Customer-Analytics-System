An enterprise-grade, end-to-end customer analytics and database intelligence platform. This system connects to a relational e-commerce database, extracts customer behavioral data, trains machine learning models for segmentation, churn prediction, and sentiment analysis, and outputs visualization graphs and reports.

## 🛠️ System Architecture

The project is structured into modular components separating the database layer, query layer, machine learning pipelines, and output models:

```
├── backend/
│   ├── __init__.py
│   ├── db.py           # Database connection & SQLAlchemy engine
│   ├── queries.py      # Predefined SQL queries for business intelligence
│   └── main.py         # Script to run analytical queries & print reports
├── ml/
│   ├── __init__.py
│   ├── customer_segmentation.py  # K-Means clustering (K=4) & model saving
│   ├── churn_model.py            # Churn prediction using Logistic Regression
│   ├── sentiment_model.py        # Sentiment analysis on review comments using TF-IDF
│   ├── find_best_k.py            # Elbow method & Silhouette score analysis for optimal K
│   ├── visualize_clusters.py     # PCA dimensionality reduction & cluster visualization
│   └── check_recency.py          # Descriptive statistical analysis on customer recency
├── sql/
│   ├── customer_features.sql     # View definition combining RFM + review metrics
│   └── Analytics.sql             # SQL script containing general analytical queries
├── models/
│   └── customer_segmentation.pkl # Serialized K-Means model (generated by ml/customer_segmentation.py)
├── data/
│   └── customer_segments.csv     # Extracted customer segments (generated by ml/customer_segmentation.py)
├── .env.example                  # Environment configuration template
├── .gitignore                    # Standard Git ignore configurations
└── requirements.txt              # Project dependencies
```

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have the following installed:
* Python 3.8 or higher
* PostgreSQL database instance

### 2. Database Setup
1. Restore or import the Brazilian E-Commerce dataset (Olist) to your PostgreSQL database.
2. Run the SQL script [sql/customer_features.sql](file:///Users/tekla/Database%20Intelligence%20Platform/sql/customer_features.sql) on your database. This view aggregates RFM (Recency, Frequency, Monetary) metrics along with customer review ratings:
   ```sql
   CREATE VIEW customer_features AS
   SELECT
       c.customer_unique_id,
       COUNT(DISTINCT o.order_id) AS number_of_orders,
       SUM(oi.price) AS total_spent,
       AVG(r.review_score) AS average_review_score,
       MAX(o.order_purchase_timestamp) AS last_purchase_date
   FROM olist_order_customer_dataset c
   ...
   ```

### 3. Installation
Clone this repository and navigate to the project directory:
```bash
git clone https://github.com/kilasoniatekla777/AI-Powered-Customer-Analytics-System.git
cd AI-Powered-Customer-Analytics-System
```

Create and activate a virtual environment:
```bash
# MacOS/Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

Install the dependencies:
```bash
pip install -r requirements.txt
```

### 4. Configuration
Create a `.env` file in the root directory based on the [.env.example](file:///Users/tekla/Database%20Intelligence%20Platform/.env.example) template:
```bash
cp .env.example .env
```
Update the database connection credentials in `.env`:
```ini
DB_HOST=localhost
DB_PORT=5432
DB_NAME=Brazilian_E_Commerce
DB_USER=your_postgres_user
DB_PASSWORD=your_postgres_password
```

## 📈 Usage & Execution

Always run the scripts from the project root using the `PYTHONPATH` environment variable, or run them as modules:

### 1. Running Database Analytics & Query Suite
Execute standard business intelligence queries (e.g. total revenue, repeat purchase rates, top products/sellers, category-wise sales):
```bash
PYTHONPATH=. python -m backend.main
```

### 2. Machine Learning Pipelines

#### Customer Segmentation (K-Means)
Train a K-Means model (using number of orders, total spent, and average review score), group customers, save the model and export CSV data:
```bash
PYTHONPATH=. python -m ml.customer_segmentation
```

#### Churn Prediction Model
Train a Logistic Regression model to predict customer churn based on behavioral features:
```bash
PYTHONPATH=. python -m ml.churn_model
```

#### Review Sentiment Analysis
Train a text classifier (TF-IDF + Logistic Regression) on review comment messages:
```bash
PYTHONPATH=. python -m ml.sentiment_model
```

#### Parameter Tuning (K-Selection)
Run Silhouette and Elbow evaluations to choose the optimal number of segments (K=5):
```bash
PYTHONPATH=. python -m ml.find_best_k
```

#### Dimensionality Reduction & Visualization
Map scaled customer behavioral data into a 2D space using PCA and plot the customer clusters:
```bash
PYTHONPATH=. python -m ml.visualize_clusters
```

## 📊 Analytical Models Overview

### 1. Customer Segmentation
Segments are calculated using K-Means. The optimal K is selected using the silhouette score ($k=5$ yielding the best separation). Features used:
- **Frequency**: `number_of_orders`
- **Monetary**: `total_spent`
- **Satisfaction**: `average_review_score`
- **Recency**: `recency_days`

### 2. Sentiment Classifier
Processes Portuguese text comments using NLP TF-IDF vectorization:
- **Input**: review comments (`review_comment_message` $\neq$ NULL)
- **Target**: binary sentiment ($1$ for review score $\ge 4$, $0$ for review score $\le 2$)
- **Algorithm**: Logistic Regression with standard L2 regularization

### 3. Churn Prediction
Determines risk of user attrition based on inactivity:
- **Definition**: Active customers are split by the median value of `recency_days`. Any customer exceeding the median threshold is flagged as churned.
- **Features**: behavioral metrics scaled using `StandardScaler`.
